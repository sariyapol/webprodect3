# MUT Shuttle — ระบบจองรถรับส่งและบริหารการเดินรถ

เว็บ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งอะไร — ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ได้เลย
ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ (ตาม ER / Mapping) และมีข้อมูลตัวอย่างย้อนหลัง 30 วัน

## ฟีเจอร์ตาม spec

- **Login / Access Control** — ตรวจ username/password, เมนูและปุ่ม เพิ่ม/แก้ไข/ลบ แสดงตามตาราง `สิทธิ์` ของ `ตำแหน่ง`, เปิด URL ที่ไม่มีสิทธิ์ → Access Denied
- **ผู้ใช้บริการ** — ค้นหารอบ (จุดลงต้องอยู่หลังจุดขึ้น, ซ่อนรอบที่เหลือเวลา < 20 นาที), รายละเอียดรอบ + route diagram, เลือกที่นั่ง ≤ 4, ยืนยัน (ตรวจที่นั่งซ้ำ), QR Code, การจองของฉัน 3 แท็บ, ยกเลิก (คืนที่นั่ง)
- **คนขับ** — งานวันนี้, ผู้โดยสารตามจุดจอด, เริ่มการเดินทาง, สแกน QR (กล้องผ่าน BarcodeDetector บน Chrome/Android หรือพิมพ์รหัส) พร้อมกรณี สำเร็จ / ผิดรอบ / ยกเลิก / ซ้ำ, ปิดงาน (สรุปผู้ใช้จริง + No Show), ประวัติ
- **หลังบ้าน** — Dashboard, CRUD ผู้ใช้งาน/พนักงาน, แผนก, ตำแหน่ง, หน้าจอ, Permission Matrix, ประเภทรถ, รถ (ทะเบียนห้ามซ้ำ), จุดจอด (ห้ามลบถ้าถูกใช้), เส้นทาง (ลากเรียงลำดับ + เวลารวมคำนวณสด), รอบการเดินรถ (ตรวจรถ/คนขับชนเวลา), การจอง (ดู/ยกเลิก/เปลี่ยนสถานะ), รายงาน 1–7 + Export CSV

## โครงสร้างไฟล์

```text
webmutbus/
├── index.html
├── css/style.css
└── js/
    ├── store.js   ฐานข้อมูล localStorage + ข้อมูลตัวอย่าง + ค่าคำนวณ (derived)
    ├── ui.js      ไอคอน, badge, modal, toast, QR
    ├── app.js     router (#/...), login, สิทธิ์
    ├── user.js    หน้าผู้ใช้บริการ
    ├── driver.js  หน้าคนขับ
    └── admin.js   หลังบ้าน + รายงาน
```

## หมายเหตุ

- QR Code ใช้ไลบรารี `qrcodejs` จาก cdnjs (ต้องมีอินเทอร์เน็ต) — ถ้าออฟไลน์จะแสดงลาย QR จำลอง + รหัสสำรองเป็นข้อความ
- รีเซ็ตข้อมูลตัวอย่างได้ที่ หน้าโปรไฟล์ → “รีเซ็ตข้อมูลตัวอย่าง”
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว หากต้องการใช้งานจริงหลายเครื่อง ต้องเปลี่ยน `store.js` ให้เรียก API/ฐานข้อมูลฝั่ง server
- password เก็บเป็นข้อความธรรมดาเพื่อการสาธิตเท่านั้น
